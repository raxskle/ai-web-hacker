# Open-source Skill для отправки ссылок и карточек в каталоги продуктов

> Создан [Flaq.ai](https://flaq.ai/) для ИИ-агентов программирования, включая Codex и Claude Code.

Основанный на доказательствах возобновляемый процесс отправки продуктов, программ, стартапов, приложений и сайтов в каталоги и другие публичные каналы обнаружения. Skill проверяет допустимость, предотвращает дубли, соблюдает границы полномочий, сохраняет ручные проверки, использует достоверные данные и ведёт аудируемый журнал.

Карточка в каталоге может дать упоминание, реферальный трафик или обратную ссылку, однако проект **не гарантирует** размещение ссылки, атрибут follow, одобрение, индексацию, трафик или рост позиций.

## Возможности

- Карточки продуктов, ПО, ИИ-инструментов, стартапов, компаний, приложений и сайтов
- Маршруты `Request app`, рекомендации, заявления на карточку и анкеты поставщика
- Разрешённое создание бесплатной учётной записи или публичного профиля
- Отправка через блоги, статьи, новости, сообщества, почту и контактные формы
- Проверка допустимости, стоимости, взаимной ссылки, аккаунта, дублей и верификации
- Статусы с доказательствами и возобновляемые журналы кампаний

## Безопасность

- Использовать только проверенные сведения о продукте, компании, основателях, ценах, контактах, собственности и юридических данных.
- Не обходить CAPTCHA, Turnstile, 2FA, passkey и подтверждение почты.
- Без отдельного разрешения не платить, не включать продление, не ставить взаимные ссылки, не менять сайт/DNS, не загружать файлы проверки и не заявлять права.
- Не считать создание аккаунта, черновик, клик или переход публикацией.
- При неясном исходе финальной отправки сначала расследовать его, чтобы избежать дубля.

## Процесс

1. Загрузить утверждённый профиль, описания, URL, материалы, правила полномочий и журнал.
2. Нормализовать и удалить дубли целевых URL.
3. Проверить доступность, соответствие, стоимость, взаимность, аккаунты, условия и дубли.
4. Собрать CAPTCHA, почту, телефон и 2FA в одну очередь ручных действий.
5. После проверки вводить только утверждённые факты и материалы.
6. Перед финальным действием повторно проверить стоимость, бренд, URL, категорию, файлы, соглашения, риск дубля и полномочия.
7. Сразу записать точный ответ, время, итоговый URL и доказательства, затем провести аудит.

## Использование

Скопируйте `submit-product-directories-v2-quality/` в каталог Skills агента или укажите папку напрямую.

```text
Используй $submit-product-directories-v2-quality для проверки URL и подготовки
кампании. Сначала проверь допустимость и верификацию. Без разрешения не публикуй,
не создавай аккаунт, не принимай соглашения и не плати. Сохрани аудируемый
журнал и одну очередь ручных проверок.
```

```bash
python3 submit-product-directories-v2-quality/scripts/audit_submission_record.py path/to/record.md
python3 -m unittest discover -s submit-product-directories-v2-quality/tests
```

`submitted` требует надёжного подтверждения приёма, а `published` — публичной страницы не в режиме предпросмотра. Клик или перенаправление не доказывает успех.
