# Skill โอเพนซอร์สสำหรับส่งแบ็กลิงก์และไดเรกทอรีผลิตภัณฑ์

> สร้างโดย [Flaq.ai](https://flaq.ai/) สำหรับเอเจนต์เขียนโค้ด AI เช่น Codex และ Claude Code

เวิร์กโฟลว์ที่อ้างอิงหลักฐานและกลับมาทำต่อได้ สำหรับส่งผลิตภัณฑ์ ซอฟต์แวร์ สตาร์ทอัพ แอป และเว็บไซต์ไปยังไดเรกทอรีผลิตภัณฑ์และช่องทางค้นพบสาธารณะ ช่วยตรวจสิทธิ์ ป้องกันการส่งซ้ำ เคารพขอบเขตการอนุญาต รักษาขั้นตอนยืนยันด้วยคน ใช้ข้อมูลจริง และบันทึกผลที่ตรวจสอบได้

การลงไดเรกทอรีอาจสร้างการอ้างอิง ทราฟฟิก หรือแบ็กลิงก์ แต่โครงการนี้**ไม่รับประกัน**การได้ลิงก์ คุณสมบัติ follow การอนุมัติ การทำดัชนี ทราฟฟิก หรืออันดับ

## สิ่งที่รองรับ

- รายการผลิตภัณฑ์ ซอฟต์แวร์ เครื่องมือ AI บริษัท แอป และเว็บไซต์
- เส้นทาง `Request app` คำแนะนำ การขอสิทธิ์รายการ และใบสมัครผู้ขาย
- การสร้างบัญชีฟรีหรือโปรไฟล์สาธารณะเมื่อได้รับอนุญาต
- การส่งบล็อก บทความ ข่าว ชุมชน อีเมล และแบบฟอร์มติดต่อ
- ตรวจสิทธิ์ ค่าใช้จ่าย ลิงก์แลกเปลี่ยน บัญชี รายการซ้ำ และการยืนยัน
- ติดตามสถานะด้วยหลักฐานและบันทึกแคมเปญที่ทำต่อได้

## หลักความปลอดภัย

- ใช้เฉพาะข้อมูลผลิตภัณฑ์ บริษัท ผู้ก่อตั้ง ราคา การติดต่อ กรรมสิทธิ์ และกฎหมายที่ตรวจสอบแล้ว
- ห้ามหลบเลี่ยง CAPTCHA, Turnstile, 2FA, passkey หรือการยืนยันอีเมล
- ห้ามจ่ายเงิน เปิดต่ออายุ เพิ่มลิงก์แลกเปลี่ยน แก้เว็บไซต์/DNS อัปโหลดไฟล์ยืนยัน หรืออ้างกรรมสิทธิ์โดยไม่มีอนุญาตแยกต่างหาก
- อย่าถือว่าการสร้างบัญชี บันทึกร่าง คลิก หรือเปลี่ยนหน้าเท่ากับเผยแพร่แล้ว
- หากผลการส่งสุดท้ายไม่ชัดเจน ให้ตรวจสอบก่อนลองใหม่เพื่อป้องกันรายการซ้ำ

## ขั้นตอนทำงาน

1. โหลดโปรไฟล์ คำอธิบาย URL ไฟล์ กฎการอนุญาต และบันทึกเดิมที่อนุมัติแล้ว
2. จัดรูปแบบและลบ URL เป้าหมายที่ซ้ำ
3. ตรวจความพร้อม ความเหมาะสม ราคา ลิงก์แลกเปลี่ยน บัญชี ข้อกำหนด และรายการซ้ำ
4. รวม CAPTCHA อีเมล โทรศัพท์ และ 2FA เป็นคิวงานด้วยคนเดียว
5. หลังยืนยันแล้ว กรอกเฉพาะข้อเท็จจริงและไฟล์ที่อนุมัติ
6. ก่อนดำเนินการสุดท้าย ตรวจราคา แบรนด์ URL หมวดหมู่ ไฟล์ ข้อตกลง ความซ้ำ และสิทธิ์อีกครั้ง
7. บันทึกคำตอบ เวลา URL ผลลัพธ์ และหลักฐานทันที แล้วตรวจสอบบันทึก

## วิธีใช้

คัดลอก `submit-product-directories-v2-quality/` ไปยังโฟลเดอร์ Skills ของเอเจนต์ หรืออ้างอิงโฟลเดอร์โดยตรง

```text
ใช้ $submit-product-directories-v2-quality ตรวจ URL ของไดเรกทอรีและเตรียม
แคมเปญส่งผลิตภัณฑ์ ตรวจสิทธิ์และการยืนยันก่อน ห้ามเผยแพร่ สร้างบัญชี
ยอมรับข้อตกลง หรือจ่ายเงินหากไม่ได้รับอนุญาต บันทึกหลักฐานที่ตรวจสอบได้
และรวมงานยืนยันด้วยคนไว้ในคิวเดียว
```

```bash
python3 submit-product-directories-v2-quality/scripts/audit_submission_record.py path/to/record.md
python3 -m unittest discover -s submit-product-directories-v2-quality/tests
```

`submitted` ต้องมีหลักฐานรับเรื่องที่เชื่อถือได้ และ `published` ต้องมีหน้าสาธารณะที่ไม่ใช่ตัวอย่าง ห้ามสรุปว่าสำเร็จจากการคลิกหรือเปลี่ยนหน้าเท่านั้น
