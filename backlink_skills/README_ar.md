# مهارة مفتوحة المصدر لإرسال الروابط الخلفية وأدلة المنتجات

> أنشأتها [Flaq.ai](https://flaq.ai/) لوكلاء البرمجة بالذكاء الاصطناعي مثل Codex وClaude Code.

سير عمل قائم على الأدلة وقابل للاستئناف لإرسال المنتجات والبرامج والشركات الناشئة والتطبيقات والمواقع إلى أدلة المنتجات وقنوات الاكتشاف العامة. تساعد المهارة على التحقق من الأهلية، ومنع التكرار، واحترام حدود التفويض، والحفاظ على التحقق اليدوي، واستخدام معلومات صحيحة، وتسجيل نتائج قابلة للتدقيق.

قد يؤدي الإدراج إلى إشارات أو زيارات إحالة أو روابط خلفية، لكن المشروع **لا يضمن** وضع الرابط أو سمة follow أو القبول أو الفهرسة أو الزيارات أو تحسن الترتيب.

## النطاق

- إدراج المنتجات والبرامج وأدوات الذكاء الاصطناعي والشركات والتطبيقات والمواقع
- مسارات `Request app` والتوصية والمطالبة بالقائمة وطلبات الموردين
- إنشاء حساب مجاني أو ملف عام عند وجود تفويض
- الإرسال عبر المدونات والمقالات والأخبار والمجتمعات والبريد ونماذج الاتصال
- فحص الأهلية والتكلفة والرابط المتبادل والحساب والتكرار والتحقق
- تتبع الحالة بالأدلة وسجلات حملات قابلة للاستئناف

## مبادئ السلامة

- استخدم فقط معلومات موثقة عن المنتج والشركة والمؤسسين والأسعار والاتصال والملكية والجوانب القانونية.
- لا تتجاوز CAPTCHA أو Turnstile أو 2FA أو مفاتيح المرور أو تحقق البريد.
- لا تدفع أو تفعل التجديد أو تضف رابطًا متبادلاً أو تعدل الموقع/DNS أو ترفع ملف تحقق أو تطالب بالملكية دون تفويض منفصل.
- لا تعتبر إنشاء حساب أو حفظ مسودة أو النقر أو الانتقال نشرًا ناجحًا.
- إذا كانت نتيجة الإرسال النهائي غامضة، فتحقق منها قبل إعادة المحاولة لمنع التكرار.

## سير العمل

1. حمّل ملف المنتج والأوصاف وعناوين URL والأصول وقواعد التفويض والسجل المعتمد.
2. وحّد عناوين URL المستهدفة وأزل المكرر.
3. افحص التوفر والملاءمة والتكلفة والروابط المتبادلة والحسابات والشروط والتكرار.
4. اجمع CAPTCHA والبريد والهاتف و2FA في قائمة يدوية واحدة.
5. بعد التحقق، أدخل الحقائق والأصول المعتمدة فقط.
6. قبل الإجراء النهائي، أعد فحص التكلفة والعلامة وURL والفئة والملفات والاتفاقيات ومخاطر التكرار والتفويض.
7. سجّل فورًا الاستجابة الدقيقة والوقت وURL الناتج والأدلة، ثم دقق السجل.

## الاستخدام

انسخ `submit-product-directories-v2-quality/` إلى مجلد Skills للوكيل أو أشر إلى المجلد مباشرة.

```text
استخدم $submit-product-directories-v2-quality لمراجعة عناوين الأدلة وإعداد حملة
إرسال للمنتج. افحص الأهلية والتحقق أولًا. لا تنشر أو تنشئ حسابًا أو توافق
على اتفاقيات أو تدفع دون تفويض. احفظ سجلًا قابلًا للتدقيق وقائمة تحقق يدوية واحدة.
```

```bash
python3 submit-product-directories-v2-quality/scripts/audit_submission_record.py path/to/record.md
python3 -m unittest discover -s submit-product-directories-v2-quality/tests
```

تتطلب `submitted` إثبات استلام موثوقًا، وتتطلب `published` صفحة عامة ليست معاينة. لا تستنتج النجاح من نقرة أو إعادة توجيه فقط.
